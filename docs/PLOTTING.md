# Create charts with LibreOffice Calc

> Use the `training.csv` generated by `agent.py`

## Open the data

1. Open LibreOffice Calc and open `training.csv`
2. Check that the preview shows three columns, then confirm:
    - A: `episode`
    - B: `steps`
    - C: `mean_squared_td_error`
3. Save a working copy as **`training-charts.ods`**
4. Keep the original CSV

## Loss convergence chart

1. Select the data in columns A through C, including the headers
   For 1,200 episodes, this is `A1:C1201`
2. Choose **Insert → Chart**
3. Choose **XY (Scatter)** and the variant with lines only
4. Choose data series in columns and use the first row as labels
5. In the **Data Series** step, keep only the loss series; remove the `steps` series from the chart
6. Set the loss series' X-values to `A2:A1201` and Y-values to `C2:C1201`.
7. Set the chart title to **Astronaut: loss convergence**, X-axis title to **Training episode**,
   and Y-axis title to **Mean squared TD error**
8. Finish the chart. Adjust the last row in the ranges if you trained for a different number of episodes

## Survival chart

1. Select `A1:B1001` and choose **Insert → Chart**
2. Again choose **XY (Scatter)** with lines only and the first row as labels
3. Check that X-values are the episode column and Y-values are the steps column
4. Title: **Astronaut: survival during training**
5. X-axis: **Training episode**. Y-axis: **Steps survived**

## Optional: smooth the loss curve

Keep the raw loss values. Add a second series with a trailing 50-episode average:

1. Enter `loss_average_50` in D1
2. In D2 enter `=AVERAGE(C$2:C2)` and fill down through D51.
   These first rows average the available episodes until there are 50
3. In D52 enter `=AVERAGE(C3:C52)` and fill down to the last data row.
   The range now moves along with each row, always including 50 episodes
4. Edit the loss chart's data ranges and add a series with column A as its
   X-values and column D as its Y-values. Label it **50-episode moving average**
5. Use a thin, light line for raw loss and a darker line for the average

## Export and preserve the results

- Save the `.ods` spreadsheet to retain charts and formulas
- Leave chart-editing mode by clicking outside the chart. Right-click the chart
  and look for **Export as Image**; choose PNG if available in your version
- For a PDF, use **File → Export As → Export as PDF**. Check the sheet's print
  layout first so charts fit on the pages
- If image export is unavailable, copy the chart into LibreOffice Draw, select
  it, and use **File → Export**, choosing PNG and **Selection** where available
- Preserve the CSV used for the final poster. Running `agent.py` again overwrites
  `training.csv`

Loss measures disagreement between Q-values and learning targets, not crashes.
Use the survival chart alongside it to assess gameplay performance.
