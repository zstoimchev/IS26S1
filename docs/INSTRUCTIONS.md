# Reinforcement learning with the Astronaut

Implement the Q-learning algorithm and train an AI agent to play the Astronaut game.

### 1. Learning to fly (0 - 5 points)

- Find an efficient way to represent a state.
- Use discrete states and the classical Q-learning algorithm, where states and actions are tabulated. 
- Determine an efficient loss function. 
- Train the agent an present the loss convergence graph.


### 2. Avoiding the asteroids (0 - 5 points)

- Add the wrapper that introduces asteroids.
- Redefine the state and retrain the agent.
- Compare the training time with the version without asteroids.


### 3. Collecting the oxygen tanks (0 - 5 points)

- Add the wrapper that introduces the oxygen tanks.
- Redefine the state and retrain the agent.
- Compare the training times of all three versions of the game.


### 4. Source code + presentation (0 - 5 points)

- Use the famnit-gym package to implement the Astronaut environment. Do not use any other libraries. 
- All search algorithms must be implemented by you in Python. No external libraries or 3rd party code is allowed.
- Create a poster in PDF format that presents your work and your findings. Follow the templates for conference posters. 
- Have a 10 minute presentation together with your colleague. Attendance and presentation is necessary to pass the seminar work.
